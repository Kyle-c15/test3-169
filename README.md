# 营养学基础高分刷题

这是一个无需构建工具的 GitHub Pages 静态答题站，题库依据 `营养学91-139.pdf` 对应教材第 65-113 页整理，共 83 题。

## 使用

直接打开 `index.html` 即可答题。也可以在 GitHub 仓库设置中将 Pages 的发布源选择为 `main` 分支根目录，等待部署后在线使用。

单选题选择后立即判分；多选题选择全部答案后点击“提交答案”。答题记录、错题和收藏只保存在浏览器 `localStorage`，不会上传到服务器。

## 本地运行

双击 `启动手机刷题服务.bat`，然后访问脚本提示的本地地址。若只在当前电脑使用，也可以使用任意静态文件服务器打开根目录。

## 题库范围

题库覆盖磷、镁、铁、锌、硒、铬、碘、铜、锰、氟，以及维生素总论、A、D、E、B1、B2、烟酸、泛酸、B6、生物素、叶酸、B12、C。每道题标注了教材页码，并按一个主考点设计，避免同一知识点的换句重复题。
